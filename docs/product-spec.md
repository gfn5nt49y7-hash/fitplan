# FitPlan 正式版产品需求说明

## 1. 产品定位

FitPlan 是面向中国大陆健身初学者的训练计划与训练记录产品。用户可以选择适合自己的训练计划，记录每次训练的重量、次数和组数，并查看每周训练进度。

正式版是允许公众注册的多用户产品，首发采用免费公开测试方式。第一阶段不收费，不提供医疗诊断，也不承诺训练效果。

## 2. 目标用户

- 18 岁以上刚开始力量训练或居家训练的用户
- 希望知道每次练什么，并持续记录训练数据的人
- 暂时不需要复杂课程、社交关系或专业康复方案的人

暂不面向未成年人、孕产期人群、术后康复人群或需要医疗监护的用户。

## 3. 用户要解决的问题

1. 不知道如何安排第一次训练。
2. 训练过程容易忘记动作、重量和组数。
3. 更换设备后无法继续查看自己的训练历史。
4. 记录很多次以后，无法快速判断一周是否完成计划。

## 4. 核心用户流程

注册登录 → 完成隐私同意 → 选择训练计划 → 查看本次动作 → 填写训练数据 → 保存 → 查看每周统计。

## 5. 首发范围

### 账号

- 手机号验证码注册和登录
- 首次登录补充昵称
- 隐私政策和用户协议确认
- 退出登录
- 注销账号并删除个人数据

### 训练计划

- 查看已发布训练计划
- 查看计划难度、预计时长和动作列表
- 查看动作说明、动作要领和安全提示
- 选择一个计划作为当前计划

### 训练记录

- 开始一次训练
- 逐个记录动作的重量、次数和组数
- 保存、编辑和删除自己的记录
- 查看最近训练历史
- 查看本周训练次数和连续打卡天数

### 数据

- 数据保存到云端并可跨设备同步
- 支持把个人训练记录导出为 CSV
- 注销账号时删除个人资料与训练记录

## 6. 暂不包含

- AI 自动生成训练计划
- 医疗、康复或疾病诊断
- 支付、会员和广告
- 好友、排行榜和公开动态
- 训练视频通话或教练实时指导
- 可穿戴设备自动同步

## 7. 角色与权限

- 普通用户：只能读取已发布计划，只能增删改自己的训练记录。
- 内容管理员：维护动作和训练计划，不能查看用户私人训练记录。
- 系统管理员：处理账号删除、内容下架和安全事件。

## 8. 数据与隐私

- 只收集完成核心功能所需的数据。
- 默认不收集医疗诊断、伤病报告或身份证信息。
- 用户训练记录默认仅本人可见。
- 隐私政策必须说明数据类型、用途、保存期限和删除方式。
- 提供账号注销与数据删除入口。
- 不向第三方出售用户个人数据。
- 正式上线前应结合实际部署位置，向云服务商和主管部门确认 ICP 备案及个人信息保护要求。

## 9. 非功能要求

- 中国大陆普通移动网络下，首页主要内容应在 3 秒内可见。
- 支持 375px 及以上移动端屏幕和常见桌面浏览器。
- 所有表单具有标签、错误提示和键盘焦点样式。
- 接口必须进行用户身份校验和权限隔离。
- 登录、发送验证码和写入接口需要限流。
- 数据库按日备份，并定期验证恢复流程。
- 关键流程异常需要记录日志，但日志不能保存验证码或完整敏感数据。

## 10. 指标

公开测试版重点观察：

- 注册完成率
- 新用户创建第一条训练记录的比例
- 7 天内完成两次训练的用户比例
- 每周仍活跃的用户比例
- 训练记录保存失败率
- 用户主动删除账号比例及原因

## 11. 上线验收条件

- 手机号注册、登录和注销流程可用
- 用户之间无法读取或修改对方数据
- 训练记录可以新增、编辑、删除和跨设备同步
- 每周统计结果与原始记录一致
- CSV 导出可用
- 隐私政策、用户协议和健康提示已上线
- 国内云资源、域名和备案状态已确认
- 自动测试、错误监控和数据库备份已启用
